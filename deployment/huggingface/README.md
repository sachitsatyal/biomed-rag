# biomed-rag

Ask a question about Alzheimer's disease research and get an answer where every claim
cites PubMed papers. The agent also searches for evidence that **disagrees**, so contested
topics show both sides.

- Code, evaluation and results: https://github.com/sachitsatyal/biomed-rag
- API docs: `/docs` on this Space

Research prototype, not medical advice. Always check the cited papers.
